# oplot

Plots that are frequently useful to us

### Modules

| [`distributions`](oplot.distributions.md#module-oplot.distributions)         | Plot distributions (density etc.) of data.                                                                      |
|---------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------|
| [`matrix`](oplot.matrix.md#module-oplot.matrix)                       | Plotting matrices and matrix-structured data                                                                    |
| [`multi_plot`](oplot.multi_plot.md#module-oplot.multi_plot)               | Plotting multiple datas in a same figure                                                                        |
| [`multiplots`](oplot.multiplots.md#module-oplot.multiplots)               | Drawing multiple plots in a single figure                                                                       |
| [`my`](oplot.my.md#module-oplot.my)                               | What matplotlib has already -- but with the interface I'd like                                                  |
| [`outlier_scores`](oplot.outlier_scores.md#module-oplot.outlier_scores)       | Visualizing various regions in a list of scores.                                                                |
| [`plot_audio`](oplot.plot_audio.md#module-oplot.plot_audio)               | Functions intended to plot waveform and spectra plus some timestamps information as vertical lines on the plots |
| [`plot_data_set`](oplot.plot_data_set.md#module-oplot.plot_data_set)         | Function to reduce and plot data in 2 or 3 dimensions                                                           |
| [`plot_mappings`](oplot.plot_mappings.md#module-oplot.plot_mappings)         | Plot mappings (e.g. dicts, Series, etc.).                                                                       |
| [`plot_stats`](oplot.plot_stats.md#module-oplot.plot_stats)               | Functions to represent the accuracy of outlier or classification algorithms                                     |
| [`sequences`](oplot.sequences.md#module-oplot.sequences)                 | Plotting sequences                                                                                              |
| [`ui_scores_mapping`](oplot.ui_scores_mapping.md#module-oplot.ui_scores_mapping) | Functions to create and plot outlier scores (or other) in a fixed bounded range.                                |
| [`util`](oplot.util.md#module-oplot.util)                           | Utils                                                                                                           |
