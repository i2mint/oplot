oplot.util.fixed_step_chunker(it, chk_size, chk_step=None, start_at=None, stop_at=None, return_tail=False)[source]#

a function to get (an iterator of) segments (bt, tt) of chunks from an iterator (or list) of the for [it_1, it_2…], given a chk_size, chk_step, and a start_at and a stop_at. The start_at, stop_at act like slices indices for a list: start_at is included and stop_at is excluded

Parameters:

  • it (Iterable) – iterator of elements of any type

  • chk_size (int) – length of the chunks

  • chk_step (int | None) – step between chunks

  • start_at (int | None) – index of the first term of the iterator at which we begin building the chunks (inclusive)

  • stop_at (int | None) – index of the last term from the iterator included in the chunks

  • return_tail (bool) – if set to false, only the chunks with max element with index less than stop_at are yielded if set to true, any chunks with minimum index value no more than stop_at are returned but they contain term with index no more than stop_at

Returns:

an iterator of the chunks

  1. If stop_at is not None and return_tail is False: will return all full chunks with maximum element index less than stop_at or until the iterator is exhausted. Only full chunks are returned here.

  2. If stop_at is not None and return_tail is True: will return all full chunks as above along with possibly cut off chunks containing one term whose index is stop_at-1 or one (last) term which is the last element of it

  3. If stop_at is None and return_tail is False: will return all full chunks with maximum element index less or equal to the last element of it

  4. If stop_at is None and return_tail is True: will return all full chunks with maximum element index less or equal to the last element of it plus cut off chunks whose maximum term index is the last term of it
